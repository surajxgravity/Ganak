# Contributing

1. Create a focused branch from main.
2. Keep each calculator or platform concern in a feature-oriented module.
3. Add tests for calculation rules, edge cases, and regressions.
4. Run
   pm run format,
   pm run lint,
   pm run test, and
   pm run build.
5. Update documentation and the engineering journal when applicable.
6. Use conventional commits and describe accessible behavior in pull requests.

Do not add external APIs to deterministic features without a documented interface, failure strategy, and privacy review.
