# Ganak

Ganak is an open-source Universal Calculation Engine: a fast, accessible, privacy-respecting home for calculators, converters, and technical utilities.

## Current release

The first vertical slice ships a registry-driven tool platform and a Unit Converter for length, mass, temperature, area, and volume.

## Development

```bash
npm install
npm run dev
npm run lint
npm run test
npm run build
```
